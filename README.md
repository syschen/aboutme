# 个人简历核心要点解析

## **教育背景与职业轨迹**
- **教育**：2008年至2012年于**郑州大学**完成全日制本科学习。
- **职业发展**：职业生涯始于创业公司，后历经**1号店/京东**、**PPTV/苏宁体育**、互联网医疗创业公司，并于**2021年加入美团**至今。

## **美团工作阶段核心贡献**
### **机审阶段（系统优化与能力建设）**
- **高可用保障**：通过**机审算法重试补偿**机制，实现了**99.6%** 的算法成功率，并通过实时与近线重试将整体成功率提升至**99.7%** 与**99.8%**，日均召回量近1000。
- **视频链路治理**：优化长音频调用耗时，并建设**无效URL过滤**、**视频转码**及**算法抽帧**能力，显著提升审核人效。
- **直播能力补齐**：在业务初期，系统梳理链路并建设了从直播流切片到音频ASR送审的完整处理能力，**复刻了短视频语音审核能力**，补齐了直播音频审核的短板。
- **人审工具赋能**：开发**蓝军投放**运营工具，实现运营自助化，将单次投放周期从**2周以上缩短至1周以内**，并节省研发人力投入。

### **人审阶段（专项优化与效能提升）**
- **成本降低**：
    - 通过**审核模式提升专项**（多轮审核+diff任务进质检），使质检人力从**65HC下降至30HC**，节省**35HC**。
    - 通过**申诉线上化二期**，优化研判流程，节约**4HC**人力。
- **质量提升**：通过**风险域拆分专项**形成专审队列，使**底线**、**生态**、**合规**三大关键标签准确率分别提升**4.21%**、**0.42%** 和**0.98%**。
- **技术优化**：通过**审核链路优化专项**，引入状态机模式进行流式编排框架改造，**抽象出状态节点和编排流程**，提升了研发效能与功能可复用性。

## **核心能力总结**
文档呈现了从**系统高可用建设**、**审核链路治理**到**人审流程优化**的完整能力链条，核心价值体现在通过**技术方案设计**与**专项治理**，在保障审核质量的同时，实现了**人力成本的大幅降低**与**审核效能的显著提升**。
